Race control

Run like a production service

The app is the workload. Most of the engineering is in keeping its data fresh and its failures short.

Pipeline
Airflow loads session time cards into Postgres, from raw files through staging to marts.
Stream
A replayer pushes archived laps through SQS as a simulated race weekend.
Service levels
API availability and latency, data freshness, data completeness, and stream lag.
Observability
Prometheus metrics, Loki logs, and Grafana dashboards, with alerts tied to the service levels.
Triage agent
When an alert fires, a read-only Claude agent gathers evidence and files a ticket with a likely root cause and a runbook link.
Delivery
Terraform on AWS, GitHub Actions for tests and deploys, then k3s with ArgoCD.
Run plan

Eight stages to the flag

Stages 1 and 2 are built and run locally on Docker Compose, and the triage agent from stage 3 is running. Public links arrive with the cloud stage.
